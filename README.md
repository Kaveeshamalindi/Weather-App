# 🌤️ Weather App

A simple and responsive Weather App built using **HTML, CSS, and JavaScript**. It allows users to search for different cities and view real-time weather information through the Open-Meteo API.

## ✨ Features

- 🔍 Search weather information by city name.
- 🌡️ Display current temperature in Celsius.
- ☁️ Show current weather conditions.
- 💧 Display humidity levels.
- 💨 Show wind speed.
- 🌧️ Display precipitation information.
- 📱 Responsive design for desktop and mobile devices.
- ⚡ Fetch weather information dynamically using APIs.
- ❌ Display error messages for invalid city searches.

## 🎨 UI Design

The application features a modern blue gradient design with:

- Beautiful blue and cyan gradient background.
- Clean white weather dashboard.
- Rounded search bar and information cards.
- Modern typography.
- Responsive layout.

## 🌐 API Integration

This project uses the following free APIs from Open-Meteo:

**1. Geocoding API**

Converts city names into geographical coordinates (latitude and longitude).

https://open-meteo.com/en/docs/geocoding-api

**2. Weather Forecast API**

Retrieves current weather information using geographical coordinates.

https://open-meteo.com/en/docs

No API key is required for non-commercial use under Open-Meteo's terms.

## 🚀 How to Run the Project

1. Clone this repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/weather-app.git
   ```

2. Open the project folder in Visual Studio Code.

3. Open `index.html` using Live Server or your browser.

4. Enter a city name in the search bar.

5. Click the Search button to view the weather information.
